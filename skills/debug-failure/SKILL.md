# Debug a failure

Reproduce once and retain the smallest useful error. Form a few hypotheses grounded in that evidence, then run the cheapest diagnostic that distinguishes them. Change the smallest relevant code, validate the original failure, and broaden validation only when risk justifies it. Avoid unchanged retries, speculative rewrites, and full log dumps. Report the cause, fix, and evidence.
