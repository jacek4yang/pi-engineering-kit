# Finish a task

Inspect repository state and the final diff. Run relevant diagnostics and the smallest meaningful tests; expand only for cross-cutting or high-risk changes. Check for accidental files, debug output, stale TODOs, generated junk, and unrelated edits. Confirm requested behavior from observable evidence. Report the result, validation, and any concrete limitation concisely.
